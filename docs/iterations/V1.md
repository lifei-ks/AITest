| 文件 | 职责 |
|---|---|

### 关键设计决策

1. **决策**：`database_url` 默认值由 `BASE_DIR` 拼绝对路径。**理由**：规避 TASK_BOOK 10.2「SQLite 相对路径随工作目录漂移」坑。
2. **决策**：`build_engine()` 独立成函数。**理由**：测试需要用环境变量指向临时库，engine 构造必须可注入（V2 起的 conftest 依赖它）。
3. **决策**：vite 显式 `host: '127.0.0.1'`。**理由**：Windows 下 vite 默认绑 IPv6 localhost，IPv4 访问 5173 会连不上（联调实测发现）。

## 环境备注（重要，影响你日常使用）

1. **PyPI 官方源网络不稳**（SSL 中断），安装用了清华镜像 `-i https://pypi.tuna.tsinghua.edu.cn/simple`。
2. **你系统里 `NODE_ENV=production`**：会导致 npm 跳过 devDependencies（vite 装不上）。构建/开发前需 `$env:NODE_ENV='development'`，或建议从系统环境变量里删掉它（待你确认）。
